# Retail Sales Analysis - EDA Project

**Tools Used:** Python, Pandas, NumPy, Matplotlib, Seaborn

### Project Objective
UK Retail ke sales data ka Exploratory Data Analysis (EDA) karke business insights nikalna.

### Key Findings
- 38 High-Value Outlier Orders Found
- Office Supplies Category ka Profit Sabse High
- UK Region Top Revenue Contributor
- Q4 Me Sales Peak Pe Hai

### Dataset
- `retail_sales_data.csv` - Raw data (2023-2024)
- `Retail_Sales_Analysis.ipynb` - Full EDA Notebook with Visualizations
